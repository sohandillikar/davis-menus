
## 🚀 Quick Start

### Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running

### 1. Clone the Repository

```bash
git clone https://github.com/sohandillikar/davis-menus.git
cd davis-menus
```

### 2. Set Up Environment Variables

Create a `.env` file in the `backend/` directory:

```bash
# backend/.env
OPENAI_API_KEY=your-openai-api-key-here
```
OpenAI is used only to generate human-readable explanations for meal planner output.  
Meal plans are generated by a classification algorithm in `backend/meal_planner.py`

### 3. Run the Application

```bash
# Start all services
docker compose up --build

# Or run in detached mode
docker compose up -d --build

# Stop all services
docker compose down
```

### 4. Access the Application

- **Frontend**: http://localhost:8080
- **Backend API**: http://localhost:8000
